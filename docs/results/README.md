## 集計と検証の範囲

一時的なインフラエラーは再試行し、成功した試行を集計。

元の500件台帳では119件にPython浮動小数点除算の表記差（最大 `2E-14` 秒）があり、その厳密不一致の検証記録は保持しています。追加500件は元metadataの `elapsed_ms` を10進数として1000で割った秒と厳密照合し、累積usageとも一致しました。最終600件はCSV・JSON・HTML間で一致し、旧100件は全キー・値・順序を保持しています。

過去100件と追加500件には計測時期の差があります。サーバー負荷、キャッシュ、接続通知の影響は分離できません。元のCLI時間を保持し、補正・除外はしていません。因果や統計的有意差を主張しません。HTMLの6条件フィルター、グラフ、件数表示、全件CSV・JSON出力は機能検証済みです。ブラウザーのスクリーンショットによる見た目の確認は行っていません。
